# Gemensamma dokumenttyper

Här kan dokumentmallar som används av flera bolag läggas till senare, exempelvis:

```text
shared/
  protokoll/
    WeAB.ott
    WeRule.ott
    ...
```

En dokumenttyp kan dela samma struktur mellan bolagen och ändå behålla varje bolags grafiska profil. Detta PR innehåller inga sådana specialmallar.
